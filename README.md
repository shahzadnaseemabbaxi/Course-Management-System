# Course Management System

Angular + JSON Server based course management dashboard.

## Features
- Dashboard with stats
- Student CRUD
- Courses, Enrollments, Fees pages
- Responsive sidebar & navbar

## Tech Stack
- Angular 17+
- TypeScript
- Bootstrap 5
- JSON Server (backend)

## How to Run
1. `npm install`
2. `json-server --watch db.json`
3. `ng serve`
